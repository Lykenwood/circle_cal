# 环时 · 环形日历

独立的原生 Android 项目，以跨日期的圆形日历为核心。可切换天、周、月三个圆环视图；日程按真实开始、结束时间绘制连续弧线，可以跨午夜、跨周、跨月。首次打开会加入四条可编辑的示例日程，其中一条跨越三天。

## 开发

使用 VS Code 打开本目录。运行 `scripts/android.sh run` 可构建并安装到一台已授权的安卓设备；`scripts/android.sh build` 只构建 APK。也可运行 VS Code 默认构建任务。

本项目需要 Android SDK 36、JDK 17 和 Gradle 8.13。默认复用上级目录的 `.tooling/android-sdk` 和 `.gradle-home`；移出本工作区时，在 `.env.local` 设置 `ANDROID_HOME`、`JAVA_HOME` 和可选的 `GRADLE_USER_HOME`。

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。运行 `scripts/test-ranges.sh` 可检查跨午夜及跨月的日期边界。

## 当前范围

- 已做：天／周／月圆环切换；周、月圆环点击日期；跨天日程按实际起止时间连续绘制，并在周／月边界裁剪；未来七天分日列表；日程增删改；设备本地保存。旧版单天日程会自动迁移，原数据留作恢复副本。
- 2025、2026 年按国务院办公厅公布的全国放假调休安排标红休息日，并排除调休上班的周末。其他年份暂按普通双休标红，界面会提示尚无调休数据。地方性假日暂未包含。
- 待做：Android 系统日历同步、真实天气／日照／月相、小组件与提醒。日视图的 06:00–18:00 背景仅为视觉辅助，不代表实际日出日落。

不需要账户或网络权限。此项目使用原创界面与图形实现。
